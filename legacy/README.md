# Classic CV Creator (2020)

Bu klasör, orijinal NetBeans Swing masaüstü uygulamasını anı / easter egg olarak saklar.

## Çalıştırma

JDK kuruluysa proje kökünden veya bu klasörden:

```bash
javac Variables.java CV_GUI.java
java CV_GUI
```

Modern uygulama içinden gizli jest ile de açılabilir (logo’ya 5 kez tıkla veya `Ctrl+Shift+L`).
